치과 전자차트 처치 버튼 정리 기준

버튼 이름 · 폴더 구성 · 마취 분리 · 치면 입력 · 상용구

처치 버튼은 진료 내용을 치과 전자차트에 기록하는 출발점입니다. 버튼의 이름과 구성이 정리되어 있으면 직원 모두가 같은 기준으로 입력할 수 있습니다. 조재연 강사가 치과 전자차트 컨설팅에서 처치 버튼을 정리할 때 쓰는 기준을 소개합니다.

글 조재연 강사 · 오스템임플란트 원클릭 전자차트 공인강사 · 2026.11.03

01 / CHECK

이런 처치 버튼은 정리가 필요합니다

01이름만 보고 어떤 처치인지 알 수 없습니다.

'간단', '1면'처럼 맥락 없는 이름은 무엇을 입력하는 버튼인지 바로 알기 어렵습니다.

02중복 버튼과 재료 전용 버튼이 섞여 있습니다.

외과 탭과 자주 하는 치료 탭에 같은 처치가 겹쳐 있거나, NI-TI·bur처럼 재료만 입력하는 버튼이 처치 버튼과 별도로 만들어져 있습니다.

03진료 흐름과 다른 폴더에 들어 있습니다.

X-ray 폴더 아래 TMJ 물리치료가 있는 것처럼, 버튼 위치가 실제 진료 순서와 맞지 않습니다.

02 / PRINCIPLES

처치 버튼 정리 기준 3가지

기준 01

버튼 이름을 명확하게, 중복은 하나로

폴더명과 처치명을 명확히 표시하고, 중복 버튼은 하나로 통합합니다.

기준 02

폴더는 실제 진료 흐름에 맞게

실제 진료 흐름에 맞춰 처치 버튼을 알맞은 폴더에 배치합니다.

기준 03

입력 항목은 처치 특성에 맞게

마취는 별도 입력하고, 치아·전악 단위를 구분합니다. 상용구는 처치에 필요한 기록 항목만 간결하게 구성합니다.

03 / CONSULTING

치과마다 따로 정리해야 하는 부분

위 기준은 같아도, 실제 버튼 목록은 치과마다 다릅니다. 컨설팅에서는 우리 치과의 버튼을 기준으로 다음 내용을 함께 정리합니다.

  • 현재 처치 버튼 전체 확인버튼마다 유지·이름 변경·폴더 이동·통합·신규 추가를 정합니다.
  • 수가표·재료대 목록과 대조치과에서 쓰는 수가표, 재료대 목록과 버튼 구성을 맞춥니다.
  • 실장님·직원 요청 반영현장에서 불편했던 버튼과 요청 사항을 정리에 반영합니다.
  • 원내 확인 후 확정정리한 결과는 원내에서 확인한 뒤 확정합니다.

이 글은 처치 버튼의 구성 기준을 다룹니다. 보험청구 기준은 다루지 않으며, 청구와 관련된 내용은 최신 고시와 건강보험심사평가원 기준으로 확인해 주세요.
