치과 전자차트 컨설팅

처치 버튼 · 치료 술식 입력 · 차팅 기준

전자차트를 쓰고 있지만 입력 기준이 직원마다 다른 치과의 원장님과 실장님을 위한 컨설팅입니다. 치과 총괄부장 실무 경험을 바탕으로 실제 진료 흐름에 맞춰 처치 버튼과 차팅 기준을 정리합니다.

01 / CONTENTS

다루는 내용

처치 버튼 구성

진료 흐름에 맞춰 처치 버튼의 구조와 위치를 정리합니다.

치료 술식 입력 기준

치료 술식별 입력 문구와 서식을 정해 입력 기준을 통일합니다.

치과 전용 차팅 기준

원장님의 진료 방식과 치과 상황에 맞춰 차팅 가이드를 만들어, 신규 직원도 같은 기준으로 입력하게 합니다.

02 / PROCESS

진행 방식

STEP 01현황 확인

카카오톡 상담으로 현재 차팅 현황과 요청사항을 확인합니다.

STEP 02컨설팅 진행

현장 방문 또는 비대면으로 처치 버튼 설정과 치료 술식 입력 기준을 정리합니다.

STEP 03기준 전달

정리한 차팅 기준과 설정 내용을 전달합니다.
